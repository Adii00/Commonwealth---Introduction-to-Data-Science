# Commonwealth Bank – Introduction to Data Science (Forage)

This repository contains my completed tasks for the virtual experience program **"Introduction to Data Science"** offered by **Commonwealth Bank** in collaboration with **Forage**.

## 📁 Contents

### Task 1: Supermarket Transactions
- Analyzed structured transactional data
- Answered business-related data queries using Excel

### Task 2: Data Anonymisation
- Anonymised sensitive customer data (e.g., names, credit card numbers)
- Applied data masking, generalisation, and column removal techniques

### Task 3: Twitter Data Insights Proposal
- Explored @CommBank Twitter data via API
- Proposed ways to extract business insights (e.g., sentiment analysis, trending topics)

### Task 4: Twitter Data – Database Design
- Designed a structured relational database to store Twitter data
- Defined tables, primary keys, and relationships for tweets, replies, retweets, and mentions

## 📌 Skills Demonstrated
- Data Cleaning and Anonymisation
- Exploratory Data Analysis (EDA)
- API Data Understanding
- Database Design Principles
- Excel/Spreadsheet Proficiency
- Business Insight Generation
